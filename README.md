# Terminal Al-Hakem

**Terminal Al-Hakem** — نظام لينكس حقيقي يعمل داخل المتصفح بدون أي تثبيت.

مبني على تقنية CheerpX (WebAssembly) — يشغل Debian Linux كامل بـ bash و apt و python و gcc، كلها حقيقية 100%.

## المميزات

- لينكس Debian حقيقي داخل المتصفح
- bash حقيقي مع كل الأوامر
- apt install يعمل فعلاً
- python, node, git, gcc كلها حقيقية
- بدون تثبيت، بدون سيرفر
- يعمل على الجوال والكمبيوتر
